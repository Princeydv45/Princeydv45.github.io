04 / A little interactive learning

Don’t just read it. Try it.

Selection sort / Live demo

Order from a little chaos.

Selection sort finds the smallest value in the unsorted part of an array, then moves it into the next position. Step through a pass and watch the sorted portion grow.

Time: O(n²) · Extra space: O(1)

This browser demo illustrates the algorithm explored in my programming practice.

Ready to sort. Start with the smallest value.
